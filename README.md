# Meus Códigos em Linguagem C - Parte 4 🚀

Repositório organizado contendo algoritmos adicionais em C focados em validação com leitura em loop e cálculo de média de valores positivos:

* `validacao_senha_otimizada.c`: Validação de senha numérica utilizando scanf diretamente no while.
* `media_valores_positivos.c`: Leitura de 6 valores, contagem dos números positivos e cálculo da média aritmética deles.
